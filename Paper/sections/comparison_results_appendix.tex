The simpler interacted comparison model includes worker characteristics and

controls. Write its formality coefficient as \(\widetilde\phi\), its informal
size coefficients as \(\widetilde\beta_g\), and its formal-minus-informal
size differences as \(\widetilde\theta_g\). Tildes distinguish these
coefficients from the preferred model's coefficients. The regression is
\begin{equation}\label{eq:formality-interaction}
  \ln(w_{ist}) = \alpha + \widetilde{\phi}F_{ist}
  + \sum_{g\neq g_0}(\widetilde{\beta}_g+
       \widetilde{\theta}_g F_{ist})D_{ig}
  + X_{ist}'\gamma+\lambda_{s\times t}+\varepsilon_{ist}.
\end{equation}

The dynamic comparison model interacts size with year but constrains the
premium to be common across formality groups. Let \(\tau\) index survey
years. The coefficient \(b_{g\tau}\) is the
size-to-solo log-wage gap for category \(g\) in that year. The model is
\begin{equation}\label{eq:dynamic-benchmark}
  \ln(w_{ist}) = \alpha
  + \sum_{\tau}\sum_{g\neq g_0} b_{g\tau}D_{ig}\mathbf{1}\{t=\tau\}
  + X_{ist}'\gamma+\phi F_{ist}
  + \lambda_{s\times t}+\varepsilon_{ist}.
\end{equation}
For the linear-trend version, define \(Trend_t=t-2008\) and let \(\delta_g\)
be the annual change in category \(g\)'s log-wage gap relative to solo work.
This gives
\begin{equation}\label{eq:trend-benchmark}
  \ln(w_{ist}) = \alpha
  + \sum_{g\neq g_0}(b_g+\delta_g Trend_t)D_{ig}
  + X_{ist}'\gamma+\phi F_{ist}
  + \lambda_{s\times t}+\varepsilon_{ist}.
\end{equation}
Two-sided tests of \(H_0:\delta_g=0\) do not reject
zero trends at 5 percent. These trends constrain premiums to be common across
formality groups, unlike the preferred 2008--2025 comparisons. The remaining
trend tables use 101+ and 11--19 workers as reference categories.
