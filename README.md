# Beyond Formality: The Firm-Size Wage Premium in Colombia

This repository contains the manuscript files for *Beyond Formality: The Firm-Size Wage Premium in Colombia*.

The repository is intentionally limited to LaTeX source files, tables, figures, and bibliography files needed to compile the paper. Raw GEIH microdata are not stored here and should be obtained directly from DANE.

## Main files

- `main.tex`: full manuscript with author details.
- `world_development_manuscript_no_author_details.tex`: anonymized manuscript for double-blind submission.
- `world_development_title_page_author_details.tex`: title page with author details.

## Folder structure

- `Paper/sections/`: manuscript sections and table fragments.
- `Paper/figures/`: figures used in the manuscript.
- `Paper/tables/`: table assets used in the manuscript.
- `Paper/references.bib`: bibliography.

## Data

Raw and processed data files are excluded from this repository. In particular, `.dta` files should not be added to this repository or synced through Overleaf.
